# ЯроSpot — Сервис аренды одежды и поиска команды для съёмок

Проект (практика) по разработке концепции и демонстрационного веб-интерфейса приложения для креативной индустрии и создателей цифрового контента.

🔗 **Ссылка на демонстрационный сайт:** https://github.io

## 📌 Описание проекта
**ЯроSpot** — это концепция кроссплатформенного приложения, разработанная для автоматизации взаимодействия участников съемочного процесса (блогеров, операторов, моделей, стилистов). Продукт совмещает в себе функции профессиональной социальной сети для поиска единомышленников и p2p-платформы для краткосрочной аренды одежды и реквизита.

### Решаемые проблемы:
1. **Хаотичный поиск команды:** Замена разрозненных чатов в мессенджерах единой структурированной лентой объявлений о съемках.
2. **Высокая стоимость визуального контента:** Доступ к каталогу стильной и трендовой одежды напрокат вместо покупки дорогих вещей ради одного кадра.

## 💻 Демонстрационный веб-интерфейс
В рамках первой части практики был разработан многостраничный веб-ресурс, который наглядно демонстрирует архитектуру, дизайн и логику работы будущего приложения.

### Структура сайта:
* **Главная страница:** Маркетинговый лендинг, презентующий основные возможности платформы ЯроSpot, её преимущества для новичков и профессионалов, а также модальную форму обратной связи для сбора заявок на участие в закрытом бета-тестировании.
* **Каталог одежды:** Демонстрационный интерфейс шеринг-платформы. Содержит карточки доступных вещей, цены за сутки аренды и статусы доступности («Свободно» / «В аренде»).
* **Поиск команды:** Прототип интерактивной ленты объявлений, где операторы, модели и блогеры могут публиковать свои творческие проекты и откликаться на чужие съемки.

## 🛠️ Стек технологий и особенности реализации
* **Фронтенд:** HTML5, CSS3 (адаптивная верстка, поддержка мобильных устройств), JavaScript (реализация интерактивных элементов).
* **Хостинг:** GitHub Pages (обеспечивает доступ к демонстрационной версии сайта 24/7 без необходимости развертывания локальных серверов).
* Для корректной работы межстраничной навигации в проекте использованы относительные пути, что гарантирует стабильное открытие ресурса на любых устройствах и серверах.

## 📂 Структура репозитория
Проект имеет четкую модульную структуру, где файлы стилей, разметки, скриптов и медиаресурсов разделены по соответствующим директориям:
* `/css` — файлы стилей оформления и кастомизации элементов интерфейса.
* `/js` — скрипты автоматизации и логики интерактивных элементов (файл `main.js`).
* `/images` — графические элементы, логотипы, примеры товаров каталога и фотографии пользователей (хранятся локально в репозитории для обеспечения автономности проекта без внешних зависимостей).
* `index.html` — главная страница сайта (лендинг).
* `catalog.html` — страница каталога одежды.
* `team.html` — страница поиска съемочной команды.
* `README.md` — сопроводительная документация к проекту.
